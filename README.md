# HomeZim 🇿🇼

Zimbabwe-wide Property Rental Marketplace — finding houses to rent across Harare, Bulawayo, Mutare, Gweru, and nationwide.

## 📱 TrebEdit Android Ready
- Built with pure **HTML5**, **CSS3**, and **Vanilla JavaScript**.
- No build tools, no Vite, no React, no Tailwind CLI required.
- Open `index.html` directly in **TrebEdit** on Android and tap **Preview (▶)**.

## 📁 Project Structure
```
HomeZim/
├── index.html       # Main marketplace layout and UI
├── css/
│   └── style.css    # Zimbabwe-themed mobile-first stylesheet
└── js/
    └── app.js       # Property listings catalog and search/filter engine
```
